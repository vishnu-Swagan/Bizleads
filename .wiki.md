# Project Summary
BizLeads is a sophisticated full-stack web application designed to enhance the online visibility of local businesses. The platform facilitates lead discovery and management through an efficient sales pipeline, transforming prospects into clients. Utilizing AI-driven insights, BizLeads provides precise business data and advanced targeting filters for direct engagement via email services. Recent updates have focused on improving the billing and payment processes, ensuring a seamless user experience.

# Project Module Description
- **Landing Page**: Marketing page with options for "Sign Up" and "Sign In."
- **Dashboard**: Displays key metrics, quick actions, and a new user tutorial.
- **Business Search**: AI-powered search for businesses using Google Places.
- **Lead Detail**: Manages individual leads with notes and interaction history.
- **All Leads**: Comprehensive view of leads with filtering options.
- **Pipeline**: Kanban board illustrating leads across various stages.
- **Analytics**: Insights into pipeline performance and key metrics.
- **Automations**: Tools for generating email drafts and managing outreach workflows.
- **Guided Tutorial**: Interactive tutorial for new users to navigate the application effectively.
- **Settings**: Configuration page for workspace and billing settings, including payment processing.

# File Description Inventory
- **frontend/src/pages/**: Contains main application pages including the landing page, pricing, dashboard, discovery, leads management, lead details, pipeline, analytics, automations, and settings.
- **frontend/src/components/**: Contains reusable UI components including the guided tutorial component.
- **frontend/src/contexts/**: Contains context providers for managing authentication and application state.
- **frontend/src/lib/**: Contains utility files for API interactions and other helper functions.
- **backend/routers/**: Contains API route definitions for handling requests related to payments and business discovery.
- **backend/services/**: Contains business logic for scoring leads, processing payments, and business discovery functionality.
- **backend/models/**: Contains database models, including the updated search_jobs model with user_id.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Backend**: FastAPI, PostgreSQL
- **Authentication**: Atoms Cloud built-in authentication using Web SDK
- **State Management**: React Query for server state, React Context for authentication
- **AI Integration**: Deepseek AI model for generating leads, follow-up emails, and daily reports
- **Google Places API**: For real-time business data integration

# Usage
1. Install dependencies for both frontend and backend:
   - Navigate to the frontend directory and execute the dependency installation commands.
2. Build the application:
   - Run the build command for both frontend and backend.
3. Run the application:
   - Start the development server for both frontend and backend.
4. To enable Google Places data, add your `GOOGLE_PLACES_API_KEY` in the Secrets panel.
5. Ensure `STRIPE_SECRET_KEY` is set in your environment secrets for the billing to work.
